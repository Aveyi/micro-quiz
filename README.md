# Онлайн-викторина

Игра в стиле Kahoot: ведущий составляет викторину и запускает игру, игроки заходят по коду комнаты и отвечают на вопросы на время, таблица лидеров обновляется в реальном времени. Два микросервиса (`content` на Python и `live` на Go), общая PostgreSQL, nginx и десктопное приложение на PySide6.

## Запуск одной командой

Нужны: **Docker Desktop** (запущенный), **Python 3.10+** и интернет при первом запуске. Из папки проекта:

```bash
python start.py      # Windows
python3 start.py     # macOS и Linux
```

Скрипт сам делает всё по шагам: создаёт `deploy/.env`, поднимает сервер (`docker compose`), загружает три демо-викторины («Мемы», «Космос», «IT и программирование»), ставит зависимости приложения и открывает его окно. Первый запуск занимает несколько минут: скачиваются образы и собираются сервисы.

**Вход ведущего:** `demo` / `demo12345`. Игрок заходит без аккаунта: «Я игрок», код комнаты и ник.

Остановить сервер (данные сохранятся):

```bash
python start.py --stop
```

Другие ключи: `--no-app` (только сервер, без окна) и `--no-docker` (сервер уже запущен, например у друга).

## Играть вдвоём

Сервер достаточно запустить на одном компьютере. На втором в приложении откройте «Приложение → Настройки сервера…» и введите `http://<IP-адрес-первого-компьютера>:8000` (оба в одной сети; скрипт при запуске подсказывает адрес). Дальше: ведущий нажимает «Провести игру» у викторины, игроки вводят код комнаты.

Приложение можно открыть и несколько раз на одном компьютере: одно окно ведущего и столько игроков, сколько нужно.

## Если что-то не работает

- **«Docker не отвечает».** Запустите Docker Desktop и дождитесь, пока он загрузится.
- **Сервер не поднимается.** Первый запуск требует интернета. Посмотрите, что с ним: `docker compose ps` и `docker compose logs` в папке `deploy`. Порт `8000` должен быть свободен.
- **Игра зависает при подключении.** На Windows адрес `localhost` иногда не работает с Docker: в «Настройки сервера…» введите `http://127.0.0.1:8000`.
- **Нет викторин у ведущего.** Запустите `python start.py` ещё раз, загрузка викторин безопасна для повторов.

## Из чего состоит

| Папка | Что внутри |

| [`content/`](content/README.md) | сервис аккаунтов и викторин (Python, FastAPI) |
| `live/` | сервис игр: комнаты, WebSocket, очки, история (Go) |
| [`desktop/`](desktop/README.md) | приложение для ведущего и игрока (PySide6), сборка `.exe` |
| `deploy/` | docker-compose, nginx, создание базы, миграции |
| [`docs/`](docs/project-context.md) | контекст проекта и [договорённости по API и протоколу](docs/quiz-design.md) |
